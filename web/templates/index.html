📊 Microsoft Power BI Architecture & Integration

DashRoute provides a fully decoupled Power BI reporting layer for executive leadership. The Python export pipeline (powerbi/export_powerbi_data.py) produces clean, validated datasets that ingest into Power BI Desktop.

4-Page Enterprise Report Specification:

  • Page 1 - Executive Overview: High-level KPIs (Total Orders, Avg & Median Duration, 90th percentile, SLA threshold violations %, Duration distribution).
  • Page 2 - Delivery Performance: Segment performance across traffic densities, weather conditions, vehicle types, and distance brackets.
  • Page 3 - Root Cause Analysis: Traffic vs Weather cross-impact matrix, high-delay bottleneck segments, and data-backed mitigations.
  • Page 4 - Data Quality: Completeness audit, missing value breakdown, unmeasured variables (e.g. prep time), and analytical boundaries.

Quick Start in Power BI Desktop:

  1. Run .\venv\Scripts\python.exe powerbi/export_powerbi_data.py to generate analytical tables in powerbi/data/.
  2. Open Power BI Desktop → Get Data → Text/CSV → import fact_deliveries.csv, dim_traffic.csv, and dim_weather.csv.
  3. Copy DAX measures from powerbi/measures.dax into your model.
  4. Review powerbi/dashboard_design.md for full canvas and theme specifications.
